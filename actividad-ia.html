Prepara una instrucción para la IA

Un prompt es el texto con el que le pides algo a una inteligencia artificial. Esta herramienta prepara esa petición a partir de tus elecciones. Para obtener la actividad, después tendrás que pegarla en ChatGPT, Copilot o Gemini.

  1. Elige el tema, el nivel y el tipo de actividad.
  2. Crea el texto con el botón rojo.
  3. Copia y pega el resultado en tu herramienta de IA.

Puedes cambiar el ejemplo por cualquier tema que quieras enseñar.
